# Depth-spectrum branch

**Status: exploratory and unrefereed. No Density Hypothesis or RH result is claimed.**

This branch retains provisional harmonic-analysis ideas around isolated off-line pair spectra, aggregate-moment cancellation, positivity-versus-depth amplification, and opposed-window explicit-formula channels. The unresolved obstacle is a noncancelling observability theorem for arbitrary actual zero configurations.

The authoritative project-wide status is in `docs/RESEARCH_MAP.md` and the publication-readiness audit.
