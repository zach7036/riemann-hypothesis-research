# Xi-prime windows and short-interval localization

> [!CAUTION]
> This directory is exploratory. The exact rational window certificates are computational statements about a scale-free functional. The proposed exact-endpoint and short-interval zeta/xi-prime transfers are not complete theorems.

Reproducible artifacts cover the optimized window functional and numerical threshold bookkeeping. Full admissibility, uniform localization, Lean integration, and independent specialist review remain open.

The main publication candidate is separate under `publication/low-multiplicity-zeta/`.
