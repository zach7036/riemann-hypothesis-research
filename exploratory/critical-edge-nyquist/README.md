# Critical Edge / Nyquist branch

**Status: exploratory and unrefereed. Not a theorem about the actual zeta zeros.**

This branch records model harmonic-analysis work on subcritical Poisson invisibility, exact endpoint resonance, the Nyquist transition scale, and finite-order nullity. Any structured-packet estimate depends on explicit packet hypotheses and should not be described as a general zero-density theorem.

The authoritative project-wide status is in `docs/RESEARCH_MAP.md` and the publication-readiness audit.
