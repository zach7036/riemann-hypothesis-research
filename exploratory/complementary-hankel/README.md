# Complementary Hankel

> [!CAUTION]
> This directory contains a historical, unrefereed exploratory draft. It is archived for transparency and reproducibility, not presented as an established zeta theorem.

Retained as finite-rank algebra and a research program: Hankel-Vandermonde factorization, complementary support accounting, binary minors, and an antipodal parity obstruction. Cauchy-Binet cancellation and arbitrary-cluster observability remain open.

## Files

- `historical_draft.md` — source note with an added status warning.
- `historical_draft.pdf` — original typeset draft; its title and wording predate the later publication audit.
- `verify_complementary_hankel.py` — computational checks for algebraic or numerical components.
- `verification.txt` — recorded output from the verification script.
