# Contributing and review

The highest-value contributions are mathematical audits.

Please open an issue or pull request for:

- a precise error in a proof, constant, or normalization;
- an earlier literature result affecting priority;
- a Lean formalization of the new low-multiplicity corollaries;
- an independent reproduction of the exact certificate;
- a clearer separation between established and exploratory claims.

Identify the exact file, theorem, equation, and first unjustified step. Exploratory branches must not be promoted to established status without a complete proof and independent review.

This repository intentionally contains no GitHub Actions workflows. Run the relevant checks manually and include commands and outputs in the pull request.
